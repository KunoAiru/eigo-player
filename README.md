# 英語音声プレーヤー

教材の音声（mp3）を検索してすぐ再生できるスマホ向け Web アプリ（PWA）です。

- 検索: `r2 3-4`（RANK2 3週目4日）、`500`（単語番号 500 を含むトラック）、`7週目`、`cd3` など。スペース区切りで AND 検索、Enter で先頭を再生
- 前/次、10秒戻し/送り、シークバー、再生速度、連続・1曲リピート・1曲で停止
- ロック画面や通知の操作ボタンに対応（Media Session）
- 前回の続きの位置を記憶

## 1. PC から配信する（同じ Wi-Fi で使う）

`start.bat` をダブルクリックします（または `node server.mjs`）。表示された「スマホで開く」の URL をスマホのブラウザで開きます。PC で開いたときはメニューに QR コードが出ます。

`英語音声/` 直下のフォルダが自動で 1 冊の教材として読み込まれます。新しい教材を足すときは `英語音声/新しい教材/CD1/*.mp3` のようにフォルダを置くだけです。
Windows のファイアウォールの確認が出たら「プライベートネットワーク」を許可してください。

## 2. スマホに取り込んで外で使う（PC 不要）

1. mp3 フォルダ（例: `toefl3800`）をスマホにコピーする（USB、Google ドライブなど）
2. スマホでアプリを開き、右上のメニュー →「フォルダを選ぶ」または「ファイルを選ぶ」で取り込む
3. 取り込んだ音声は端末内に保存され、オフラインで再生できます

アプリ本体は GitHub Pages で公開しています: https://kunoairu.github.io/eigo-player/
スマホでこの URL を開き、「ホーム画面に追加」すればオフラインでも起動できます。
`main` に push すると `.github/workflows/pages.yml` が `public/` だけを公開します（音声はこのリポジトリに含めません）。

## ファイル構成

- `server.mjs` … PC 用サーバー（依存なし、Node.js 18+）
- `public/` … アプリ本体（このフォルダだけで静的ホスティング可）
  - `id3.js` … mp3 タグ（Shift-JIS 対応）の読み取り
  - `db.js` … 端末内保存（IndexedDB）
  - `sw.js` … オフライン起動用。アプリを更新したら `CACHE` の版数を上げる
