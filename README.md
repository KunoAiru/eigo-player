# TOEFL対策アプリ

教材の音声（mp3）の再生、単語帳、イディオム帳、リスニング練習、瞬間英作文、シャドーイングができるスマホ向け Web アプリ（PWA）です。

- 検索: `r2 3-4`（RANK2 3週目4日）、`500`（単語番号 500 を含むトラック）、`7週目`、`cd3` など。スペース区切りで AND 検索、Enter で先頭を再生
- 前/次、10秒戻し/送り、シークバー、再生速度、連続・1曲リピート・1曲で停止
- ロック画面や通知の操作ボタンに対応（Media Session）
- 前回の続きの位置を記憶

## 1. PC から配信する（同じ Wi-Fi で使う）

`start.bat` をダブルクリックします（または `node server.mjs`）。表示された「スマホで開く」の URL をスマホのブラウザで開きます。PC で開いたときはメニューに QR コードが出ます。

`英語音声/` 直下のフォルダが自動で 1 冊の教材として読み込まれます。新しい教材を足すときは `英語音声/新しい教材/CD1/*.mp3` のようにフォルダを置くだけです。
Windows のファイアウォールの確認が出たら「プライベートネットワーク」を許可してください。

## 2. スマホに取り込んで外で使う（PC 不要）

1. mp3 フォルダ（例: `toefl3800`）をスマホにコピーする（USB、Google ドライブなど）
2. スマホでアプリを開き、右上のメニュー →「フォルダを選ぶ」または「ファイルを選ぶ」で取り込む
   フォルダを選べないスマホでは、教材フォルダ（CD1, CD2 … と vocab.json）を丸ごと ZIP にして「ファイルを選ぶ」で選ぶ（無圧縮の ZIP なら大きくても速い）
3. 取り込んだ音声は端末内に保存され、オフラインで再生できます

アプリ本体は GitHub Pages で公開しています: https://kunoairu.github.io/eigo-player/
スマホでこの URL を開き、「ホーム画面に追加」すればオフラインでも起動できます。
`main` に push すると `.github/workflows/pages.yml` が `public/` だけを公開します（音声はこのリポジトリに含めません）。

## 3. 単語帳（Kindle のスクリーンショットから作る）

購入した Kindle 本を自分で学習するための機能です（私的利用のみ）。本の内容（vocab.json・スクショ）は
このリポジトリに含めず、GitHub にも公開しません（`.gitignore` 済み）。

1. Kindle for PC で本を開き、最初の単語ページ（RANK1 の 0001）を表示する
2. 撮影しながら読み取る（100 枚ごとに読み取り、済んだ画像は削除）

   ```
   py tools/capture.py --batch 100 --delete --engine claude
   ```

   - Kindle は他のウィンドウの裏にあっても撮影・ページ送りできます（最小化はしない）。止めるときは Ctrl+C、再実行で続きから
   - 巻末の索引まで来たら止めてかまいません（索引のページは読み取りの対象から外してください）
   - 読み取り方を直したときは、画像を残しておけば `py tools/extract.py --engine windows --force` で撮り直さずに読み直せます
   - `--engine claude` … 高精度。Anthropic の API キー（`ANTHROPIC_API_KEY`）と `py -m pip install anthropic` が必要（有料）。`--model` でモデルを変更可
   - `--engine windows` … 無料・オフライン（Windows 標準 OCR）。品詞・同義語・反意語の四角いマークは画像から見つけて拡大して読む。発音記号は保存しない。派生語などに少し読み違いが残る
   - 撮影だけしておき、あとで `py tools/extract.py --engine ...` で読み取ることもできます
3. まとめる: `py tools/build_vocab.py` → `toefl3800/vocab.json` ができる（番号の抜けや訳語の空も表示）
4. PC のサーバーなら自動で読み込まれます。スマホにはメニューの「単語データを取り込む」で vocab.json を選ぶ

アプリの使い方
- 「単語帳」タブ: 検索、★お気に入り、RANK 絞り込み。単語をタップで詳細（品詞ごとの訳・派生語・同義語・反意語・例文・補足）
- 音声の一覧の「単語 40」/ 再生中の「単語」ボタン: その音声に収録されている単語だけを表示（本の「CD 1-4」表示で対応づけ）
- 「カードで学習」: タップで裏返し、英→日 / 日→英、シャッフル、左右スワイプで前後、★登録
- 「✎ マイ単語」: 自分で単語を追加できます（「＋ 追加」、または瞬間英作文・シャドーイングの英文の単語をタップ）。
  単語帳（vocab.json）・イディオム・マイ単語のどれかにすでにある単語は追加できません（大文字小文字・前後の記号の違いは同じ単語とみなす）。
  マイ単語は端末（ブラウザ）に保存されます。メニューの「マイ単語のバックアップ」で書き出し・読み込みができます

## 4. リスニング（TOEFL 2026 形式の練習動画で答え合わせ）

「リスニング」タブで、YouTube の 2 つのプレイリスト（TOEFL Tutor Tatiana の模試 15 本、Tutor Nadeen の形式別 64 本）を解けます。

- 動画は YouTube の埋め込みプレーヤーで再生します（問題文と選択肢は動画の画面に出ます）。イントロは飛ばし、解答キーの手前で自動的に止まります
- 問題番号ごとに A〜D をタップすると、その場で ○× と正解を表示します。結果は端末に保存され、一覧に「正解数/問題数」が出ます
- YouTube Premium のアカウントでログインしているブラウザなら広告は出ません（iPhone の Safari ではサイト越えトラッキングの設定によってはログインが認識されないことがあります）
- 解答キーは各動画の解答画面から読み取ったものです（`tools/listening_keys.json`）。`?` は解答画面が切れていて読めなかった問題（採点しない）、小文字は一部が切れていて推定した解答です

データの作り直し・動画の追加:

```
node tools/build_listening.mjs
```

- `YT_API_KEY` 環境変数（または `tools/.youtube_key`）に YouTube Data API v3 のキーがあれば API で、なければ公開ページから、プレイリストの動画・長さ・チャプターを取り直して `public/listening.json` を作ります
- プレイリストを増やすときはスクリプト冒頭の `PLAYLISTS` に追加。新しい動画は `tools/listening_keys.json` に `"動画ID": {"end": 問題が終わる秒, "groups": [["Questions 1-20", "ABCD…"]]}` を足すと答え合わせできます（必要なら `"start"` で開始秒、チャプターが間違っている動画は `"chapters": false`）

## 5. イディオム

「イディオム」タブで、英語イディオム 1,539 件（和訳つき）を一覧・検索・カードで学習できます。

- 頭文字（A〜Y）で絞り込み、★お気に入り、検索（英語・訳語・番号）
- 「カードで学習」: タップで裏返し、英→日 / 日→英、シャッフル、左右スワイプで前後
- データは `public/idioms.json`（`{no, word, group, senses: [{meanings: [和訳]}]}`）。アプリに同梱しているのでオフラインでも使えます

## 6. 瞬間英作文

「瞬間英作文」タブで、短い日本語の文を見て 1〜3 秒以内に英語で言う練習ができます。

- レベル（初級・中級・上級）と制限時間（1・2・3 秒）を選んで「スタート」。時間が来ると答えが表示され、読み上げられます
- 「○ 言えた」「× 言えなかった」で自己採点。× の文は「苦手」に入り、2 回続けて言えるまでときどき出題されます
- 英文の単語をタップすると意味の確認（単語帳・イディオム・マイ単語から検索）とマイ単語への追加ができます
- 「この文をシャドーイング」でその文をシャドーイングタブで練習できます

## 7. シャドーイング

ブラウザ内蔵の読み上げ（Web Speech API、無料・オフライン可の声もあり）で、1 文ずつ段階的に練習します。
シャドーイング研究（門田修平ほか）で提案されている段階的な練習法に沿っています。

1. 聞く … 英文を見ずに聞き、日本語訳で意味をつかむ
2. マンブリング … 英文を見ずに小声でブツブツ追いかける
3. オーバーラッピング … 英文を見ながら音声と同時に読む（読み上げ中の単語がハイライトされます。ハイライトは声によっては非対応）
4. プロソディ・シャドーイング … 英文を見ずに、イントネーション・リズム重視で追いかける
5. コンテンツ・シャドーイング … 意味を思い浮かべながら追いかける
6. チェック … 穴埋め（少なめ・多め・全部＝ディクテーション）で聞き取りを確認

- 速度（0.5〜1.3 倍）、繰り返し回数、「間をあける（リピーティング）」、「終わったら次のステップへ」（①→⑤を自動で進む）
- 「🎙 録音」: お手本と一緒に（または自分だけで）録音し、「自分の声」「お手本 → 自分の声」で聞き比べ
- 「🗣 発音チェック」: 音声認識（Chrome / Edge / Safari）で言った英語を聞き取り、聞き取れなかった単語を赤で表示・点数化（文ごとのベストを記録）
- 「英文を貼り付けて練習」: ネットの英文（[VOA Learning English](https://learningenglish.voanews.com) などパブリックドメインの記事がおすすめ）を貼ると 1 文ずつに分けて練習できます
- 読み上げの声はメニューの「読み上げの声」で選べます（Edge の Natural、Chrome の Google の声が自然）

例文は [Tatoeba](https://tatoeba.org) の日英対訳（CC BY 2.0 FR）から、単語の頻度と長さでレベル分けした 2,100 文です（`public/sentences.json`）。
作り直すとき（文の数を変えるときなど）:

```
py tools/build_sentences.py --per-level 700
```

Tatoeba のデータ（`jpn_sentences`・`eng_sentences`・`jpn-eng_links`）を `tools/.tatoeba/` にダウンロードして使います（Git には含めません）。

## ファイル構成

- `server.mjs` … PC 用サーバー（依存なし、Node.js 18+）
- `public/` … アプリ本体（このフォルダだけで静的ホスティング可）
  - `id3.js` … mp3 タグ（Shift-JIS 対応）の読み取り
  - `db.js` … 端末内保存（IndexedDB、音声と単語データ）
  - `vocab.js` … 単語帳・単語の詳細・フラッシュカード
  - `idioms.json` … イディオムと和訳（イディオムタブ）
  - `listening.js` / `listening.json` … リスニング練習（YouTube 埋め込み・答え合わせ）とそのデータ
  - `speech.js` … 読み上げ・音声認識・録音（ブラウザの無料機能）と、言った英語の照合
  - `sentences.js` / `sentences.json` … 例文データ（Tatoeba）と、単語タップのポップアップ
  - `drill.js` … 瞬間英作文 / `shadow.js` … シャドーイング
- `tools/` … 単語データ作成（Python 3.10+、Pillow・numpy）
  - `capture.py` … Kindle の自動ページ送りと撮影 / `extract.py` … 読み取り / `build_vocab.py` … vocab.json にまとめる
  - `winocr.ps1` … Windows 標準 OCR の呼び出し
  - `build_sentences.py` … Tatoeba から sentences.json を作る
  - `sw.js` … オフライン起動用。アプリを更新したら `CACHE` の版数を上げる
